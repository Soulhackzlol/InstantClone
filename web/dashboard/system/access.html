OBS dock URL
The OBS dock can't sign in, so paste this token URL as its Custom Browser Dock. It runs the stream (delay, cut, destination on/off) and flips its own switches (arm when OBS connects, activate when ready, crash protection, trace log), but never reveals your keys or changes any other setting.
Ports
Changes apply when you save, no restart. A new Web UI port moves this page there. After a new stream port, OBS needs it too: a registered OBS service follows it if OBS is closed when you save. With OBS open, close it and press Update on the OBS tab.
