Format & audio
Vertical needs a 9:16 canvas from OBS. Set it up once:
  1. OBS Settings → Stream: turn on Enhanced Broadcasting (Multi-track via InstantClone on the InstantClone service).
  2. Under Additional canvas, pick your vertical canvas (for example Aitum Vertical).
Every vertical destination reuses it. With a Twitch destination enabled, Twitch decides instead, so the channel needs Dual Format on. Until a 9:16 canvas arrives, this destination waits and sends nothing.
For YouTube, paste the vertical stream key from YouTube's Dual stream → Select key → Encoder.
Twitch needs no format setting: InstantClone passes on whatever OBS sends, Enhanced Broadcasting included. With Twitch Dual Format on, it sends both canvases. How to enable Twitch Dual Format →
Auto: Twitch keeps both tracks, other platforms get the live one. Most setups can leave it.
When to change it If OBS sends a second audio track (via the VOD unlocker script or Enhanced Broadcasting), choose what this destination gets. Classic use: send Track 2 (music stripped) to YouTube to dodge copyright while Twitch keeps Both. Only Twitch consumes a second audio track, so other platforms always send a single one. If the track you pick isn't being sent, the live track is used instead, so a destination never goes silent.
Twitch VOD audio
A second audio track saved only to your Twitch VOD: keep copyrighted music in the live stream but out of the recording. OBS locks its built-in VOD Track to the service literally named "Twitch", so on the InstantClone service you unlock it with a tiny optional script.
With Streamlabs, nothing to install: in Streamlabs, Settings → Output, turn on Twitch VOD Track (under Streaming in Advanced mode) and pick the audio track without the music.
VOD unlocker script
Why a script?
OBS hardcodes the VOD Track to the service named "Twitch". The script attaches the exact same second audio encoder OBS's built-in VOD Track would, just without that lock, so it works on the InstantClone service. It touches nothing else.
On OBS older than 32.2? Old VOD Track method
How to set it up in OBS
  1. Settings → Stream: Service = Custom…, Server = the URL on the OBS tab, Key = main
  2. Settings → Output: Output Mode = Advanced, then tick VOD Track under the Streaming tab
  3. Close OBS, save this destination, then reopen OBS. (The config can't change while OBS is running.)
Keep Enhanced Broadcasting too?Experimental
VOD audio normally turns off EB's quality ladder. To run both, launch OBS from here: it passes a one-time flag OBS needs for Custom RTMP.
    Shortcut = one double-click to start InstantClone + OBS in this mode.
    Why launch from here?
    OBS ignores config-URL injections for Custom RTMP, so the only way to enable EB is the --config-url launch flag. It's per-launch: reopening OBS normally drops EB until you click here again.
